## 🛠️ Tech Stack & Ekosistem
- **Backend Framework**: PHP 8.2+ / Laravel 11.x/12.x
- **Database & Cache**: PostgreSQL / MySQL, Redis
- **Frontend Integration**: Blade + Tailwind CSS, Inertia.js (React / Vue)
- **API & Security**: RESTful API, Laravel Sanctum, RBAC (Spatie)
- **Asynchronous & Real-Time**: Background Queues/Jobs, Laravel Reverb (WebSockets)
- **QA & Testing**: Pest PHP / PHPUnit
- **DevOps**: Docker dasar, GitHub Actions CI/CD, Cloud Deployment
